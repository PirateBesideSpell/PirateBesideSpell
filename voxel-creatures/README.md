# Voxel Bestiary

Десять автономных HTML-файлов с воксельными 3D-существами по референсам. Готовые файлы находятся в `dist/`; интернет и локальный сервер для просмотра не нужны.

## Управление

- ЛКМ + движение — вращение, колесо — масштаб, `R` — сброс камеры.
- Кнопки `IDLE`, `WALK`, `RUN`, `ATTACK`, `HIT`, `DEATH` переключают костные анимации.
- `WALK` и `RUN` проигрываются на месте, чтобы их можно было использовать в игре.
- `ATTACK` и `HIT` возвращаются в `IDLE`; `DEATH` удерживает последний кадр и запускается повторно кнопкой.
- `VFX ON/OFF` отключает эффекты, `AUTO` вращает камеру, ползунок меняет скорость анимации.

## Игровая лёгкость

- Настоящие `THREE.Bone`, `THREE.Skeleton` и `THREE.SkinnedMesh`; каждый воксель жёстко привязан к одной кости.
- У девяти переработанных существ 2 091–4 416 вокселей, 9 492–20 624 видимых треугольника и 5–12 костей. Drizzlefin сохранён в исходной версии.
- Между соседними вокселями скрытые грани и их неиспользуемые вершины удаляются.
- Один общий geometry buffer для основной модели и один для светящихся деталей.
- VFX: до 80 частиц или инстансированных элементов; электрические дуги и линии используют динамические buffer geometry.
- У Drizzlefin нет частиц-капель: только водные ленты и кольца.
- Pixel ratio ограничен до 1.75, рендер останавливается в скрытой вкладке.

У каждого существа отдельная VFX-система: листья Mosswisp, пламя хвоста Flaremop, растущие изумруды Craggle, падающие лепестки Bloombyte, дуги между ушами Voltik, созвездия Noctilume, призменные геоды Prismole, облачные завитки Aeronook и гравитационная линза Eclipseed.

Кольца Eclipseed вращаются от времени кадра: idle — базовая скорость (0.16 и −0.12 рад/с), walk — ×1.6, run — ×7, attack — рывок примерно на 90°, hit — короткая дрожь, death — плавная остановка. Скорость меняется плавно и учитывает ползунок скорости анимации.

Текущая модель и риг доступны в консоли через `window.__voxel`. Исходные параметры существ — в `creatures-v2.js`, воксельные генераторы — в `voxel.js`.

## Пересборка

```sh
node build.js
```

Для сборки нужны `.build/three.min.js` и `.build/THREE-LICENSE.txt` (Three.js 0.160.1). В готовые HTML Three.js и лицензия уже встроены.
